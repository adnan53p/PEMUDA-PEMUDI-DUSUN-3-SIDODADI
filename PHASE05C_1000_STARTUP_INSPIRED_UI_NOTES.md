# Phase 05C — 1000 Startup Digital inspired UI

Scope: presentation layer only.

Main changes:
- Plus Jakarta Sans becomes the primary display/body typeface.
- Palette shifts from forest green to energetic royal blue + coral red + yellow accent, inspired by the red/blue visual language visible in official 1000 Startup Digital materials.
- Hero rebuilt as a bright editorial split layout.
- Rounded pill navigation and CTA buttons.
- Color-block impact metrics.
- Program cards redesigned as clean startup-style tiles.
- Documentation uses bold color-backed photo blocks.
- Final CTA uses a strong blue campaign panel.

Not changed:
- Supabase Auth / RLS / RPC / database
- role permissions
- finance logic
- ImageKit integration
- Edge Functions
- PDF/report logic
