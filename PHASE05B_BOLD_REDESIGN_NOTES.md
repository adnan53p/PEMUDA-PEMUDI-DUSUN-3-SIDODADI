# Phase 05B — Bold Visual Redesign

Perubahan ini sengaja dibuat jauh lebih terlihat dibanding Phase 05 awal.

## Fokus
- Hero berubah total menjadi dark editorial hero dengan grid texture, foto framed, dan CTA kontras.
- Impact stats menjadi strip metrik besar dengan panel accent.
- Section kegiatan memakai featured editorial block dark green.
- Program menjadi dark section dengan cards kontras dan accent card.
- Dokumentasi menjadi masonry-like gallery dengan headline besar.
- CTA akhir berubah menjadi accent block besar.
- Tidak menyentuh Supabase Auth, RLS, RPC, finance logic, ImageKit, atau Edge Function.

## Deployment
1. Copy patch ke root project dan replace file.
2. `npm run build`
3. `git add .`
4. `git commit -m "Phase 05B bold visual redesign"`
5. `git push`
